- [Hermes Agent source](https://github.com/NousResearch/hermes-agent)

Hermes officially documents the Android CLI path. Its Desktop documentation
lists macOS, Windows, and Linux. This repository covers the experimental bridge
between those two supported surfaces.

## Termux:X11

- [Official Termux:X11 repository and setup](https://github.com/termux/termux-x11)

The upstream setup requires both the Android Termux:X11 APK and the companion
`termux-x11-nightly` package. A PRoot environment must be entered with
`--shared-tmp` so X11 sockets are visible on both sides.
